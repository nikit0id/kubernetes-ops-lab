# Восстановление k3s и PostgreSQL

`bash scripts/k3s/dr.sh` выполняется после развёртывания приложения. Скрипт сохраняет snapshot embedded etcd, server token, пароли узлов k3s и логический дамп PostgreSQL в закрытый каталог на Docker-хосте. Для репетиции это отдельное от кластерных томов хранилище на том же хосте. Резервные копии содержат секреты и исключены из CI-артефактов.

Скрипт создаёт отдельный Compose-проект с пустыми томами и независимыми портами. В нём выполняется cluster-reset из snapshot, восстановление узлов, затем pg_restore в запущенный PostgreSQL. Скрипт проверяет наличие контрольной строки, отсутствие строки после бэкапа и ответ API /health. В CI исходный временный кластер останавливается для освобождения памяти. При локальном запуске исходный кластер продолжает работать. После проверки удаляются только временные тома и контейнеры восстановления.

В артефакте `k3s-evidence/dr.txt` RTO измеряется с момента начала восстановления до успешной проверки данных и API. RPO показывает возраст контрольной точки БД на момент начала восстановления. Значения относятся к небольшому тестовому набору на конкретном runner.
